# 管家 (GuanJia) v0.12.0-alpha

一句话指令驱动的本机全能 AI Agent。
- Tech: Tauri 2 + React 19 + Rust + SQLite + Ollama, 端口 1420
- 核心：ReAct 编排循环（意图→选工具→执行→观察→迭代），23 类工具，中文对话界面
- 管家能力：系统信息、进程、文件扫描/读写、shell 命令（带安全护栏）、打开应用、定时提醒、记忆、桌面通知
- 自进化：历史经验按意图相关度检索，区分成功经验与失败复盘，越用越懂你
- 兼容 qwen2.5-coder:7b 等本地小模型的三种工具调用输出格式
- 模型：界面自选 Ollama 模型，切换前真发请求探活（拒绝不可用/embedding 模型），偏好持久化跨重启
- 状态：v0.12.0 alpha，指令驱动 Agent + 本机/云模型自选(OpenAI 兼容) + 文件管家自定义忽略目录与多选删除 + 应用管家 + 进程终止建议 + 对话历史持久化已可用
- v0.9.0 稳定性：流式输出（Ollama NDJSON / OpenAI SSE）+ 停止按钮；破坏性操作二次确认；危险命令黑名单绕过防护；UTF-8 安全截断；语义搜索 embedding 端点修复；API Key 脱敏；云请求 429/5xx 指数退避
- v0.10.0 多工具并行：模型一次返回多个工具调用时并发执行（JoinSet），按序回填；确认桥接改多槽 id 匹配；轨迹按 step+call_id 区分并行任务
- v0.11.0 经验与记忆：经验检索改 bge-m3 语义相似度(70%)+词面(30%)混合打分，embedding 不可用自动降级；经验记录参数与结果摘要并标注并行/顺序；历史消息带工具轨迹回放，模型能看到上次怎么解决；系统提示词同步支持多工具并行输出
- v0.12.0 自动执行：设置页新增 Agent 自动执行三档（默认 safe：清理缓存免确认）；可设清理释放量阈值，超限仍确认；system prompt 明确禁止「已清理」后再让用户手动确认，修本地小模型幻觉复述
